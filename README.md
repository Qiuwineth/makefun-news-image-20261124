# The World on Tuesday — 24 November 2026

A one-page newspaper poster summing up Tuesday 24 November 2026's world
news: the Houthi strike on Riyadh's tallest tower, Ukraine's naval drones
sinking a Russian corvette in Benghazi port, and the day's other major
stories from Zaporizhzhia to Senegal.

`poster.py` draws the image with a hand-written 5×7 bitmap font and a
tiny PNG writer (pure standard library). `main.py` is the packed entrypoint
produced from it by the kit's `makefun compress`.
